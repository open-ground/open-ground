# 数据交换中心 — 设计方案 & 进度

## 一、设计目标

面向数据集市场景，结合 land 调度工具，提供统一的跨数据源数据交换能力：

1. **从库到文件** — 数据库导出到文件（CSV/分隔符格式）
2. **从文件到库** — 文件导入到数据库（多数据库兼容）
3. **从库到库** — 数据库之间的数据迁移（跨数据源同步）

## 二、整体架构

```
                       │

│                                                      │
│  TaskExchangeConfigController → Service → Mapper     │
```

## 四、配置存储表

表名：`DMP_DATA_EXCHANGE_CONFIG`（存储在共享中心库）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(32) | 主键 |
| `task_name` | varchar(200) | 任务名称 |
| `task_type` | varchar(20) | FILE_TO_DB / DB_TO_FILE / DB_TO_DB |
| `source_ds_id` | bigint | 源数据源ID（关联 sys_datasource） |
| `target_ds_id` | bigint | 目标数据源ID |
| `source_query` | text | 源端查询SQL |
| `source_file_path` | varchar(500) | 源文件路径 |
| `target_table` | varchar(200) | 目标表名 |
| `target_file_path` | varchar(500) | 目标文件路径 |
| `file_delimiter` | varchar(10) | 文件分隔符 |
| `file_encoding` | varchar(20) | 文件编码 |
| `write_mode` | varchar(20) | APPEND / TRUNCATE / MERGE |
| `batch_size` | int | 批大小 |
| `column_mappings` | text | 列映射 JSON |
| `thread_count` | int | 并行线程数 |
| `status` | varchar(10) | ENABLED / DISABLED |
| 审计字段 | - | create_time / update_time / create_by / update_by / del_flag |

## 五、API 端点

| 端点 | 方法 | 说明 | 服务端口 |
|------|------|------|:-------:|
| `/task/exchange/config/list` | POST | 配置列表（分页） | 8087 |
| `/task/exchange/config/get` | POST | 配置详情 | 8087 |
| `/task/exchange/config/save` | POST | 新增/更新配置 | 8087 |
| `/task/exchange/config/delete` | POST | 删除配置 | 8087 |
| `/sys/datasource/listAll` | POST | 数据源列表（复用） | 8086 |
| `/sys/datasource/{id}/tables` | GET | 数据源表列表（复用） | 8086 |
| `/sys/datasource/{id}/tables/{table}/columns` | GET | 表字段列表（复用） | 8086 |

## 七、代理配置（vite.config.js）

```js
  changeOrigin: true

  target: 'http://127.0.0.1:8086',
  changeOrigin: true
}
```
